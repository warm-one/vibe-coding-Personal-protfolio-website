## 背景

想有一个属于自己的线上门面，也想把 Astro 这套技术栈完整地练一遍，于是动手做了这个站。

## 我做了什么

- 用 Astro 的内容集合管理作品，新增一个作品只需要加一个文件
- 内容页面不加载 JavaScript，需要交互的地方才作为 island 按需加载
- 用 Tailwind 配了一套暗色主题，并做了响应式

## 结果

站点能正常构建、本地可以运行，结构上也留好了以后继续加作品的位置。这是练手项目，边做边学。
