## 起点

我想要一个打开就能写的 Markdown 记事本，不必注册账号，也不必把私人笔记交给云端。常见的轻量编辑器往往把书写、预览和文件管理拆开，记录一段内容需要来回切换。

## 方案与取舍

- 把笔记列表、Markdown 编辑区和实时预览放进三栏工作台，缩短记录到检查排版的路径
- 用 IndexedDB 保存笔记，并在不可用时回退到 localStorage；数据留在当前浏览器
- 加入全文搜索、代码高亮，以及 Markdown 和独立 HTML 导出，让内容能带走
- 不做账号和云同步，换设备访问时不会自动带上笔记，换取更直接的本地使用方式

## AI 协作

我用 AI 辅助拆解需求和实现功能，再围绕“打开即写、数据留在本地、结果可导出”检查交互是否服务于原始需求。产品边界和取舍由我来定，AI 帮我更快完成实现与迭代。

## 当前交付

这是一个纯前端应用，不需要账号或后端服务。页面上方可直接加载在线版本体验。笔记保存在浏览器本地，清除浏览器数据前应先导出备份。
