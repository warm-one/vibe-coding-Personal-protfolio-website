## The starting point

The first version was already on GitHub, but it read more like a project list: the personal positioning was vague, project pages listed features without explaining where the need came from, and visitors had no clear way to try the work. The portfolio itself needed to show how I identify a problem, use AI to build a solution, and deliver something people can try.

## Design and implementation

- Manage projects with Astro content collections and maintain Chinese and English content separately
- Use static HTML and small inline scripts for interactions to keep the homepage runtime lean
- Add light and dark themes, language switching, project filters, and embedded demos
- Structure project pages around the need, key trade-offs, AI collaboration, and current delivery

## AI collaboration and validation

I use AI to help shape page structure, implement components, and inspect issues, then verify the bilingual routes, theme switching, and project demos through local builds and page checks. I own the product and content decisions, while AI speeds up implementation and iteration.

## Current status

The site builds as a static deployment with Chinese and English pages for the homepage and project details. The portfolio still has a small number of projects, so I will add real work and process notes instead of inventing metrics to fill the space.
