## 1. 产品概述

一句话：**一个加载快、看着干净的个人作品集 + 博客站**——既能展示我做过的项目，也能持续写点东西；支持**中英双语**和**明暗主题切换**。

**从调研到需求（想要什么 → 满足什么）**

| 调研结论（想要什么） | 用哪条需求去满足 |
| --- | --- |
| 想长期攒内容、沉淀经验 | **博客**：自己站首发，同步平台时指回原站 |
| 暗色已是主流，明暗切换是"有没有"的问题 | **多主题**：浅色 / 暗色 / 跟随系统 |
| 想让更多人能看懂 | **多语言**：中英双语 · 全站 |
| （后续）想知道有没有人看 | **访问统计**：轻量，访问量 + 热门页 |
| 写不下去是最大风险 | **让"写一篇"尽可能省事**（内容与页面分离） |

---

## 2. 目标用户

- **主要读者（访客）**：未来的雇主 / 面试官、潜在合作者。**停留短（6–8 秒）**、先看手机、只看重点。
- **开发者（我）**：走 vibe coding 路线。诉求是练手，以及一个**长期可维护、越攒越值钱**的门面。
- **判断标准**：访客不需要思考"该看哪"，一眼扫过就知道我值不值得联系。

## 3. 功能清单

### 3.1 必须做（MVP）

**A. 作品集本体**（已上线，本轮保持即可）
- **首页 Hero**：姓名、一句话定位、1–2 句简介、主视觉、「查看作品 / 联系我」两个入口。
- **作品列表**：按时间倒序、精选置顶；每条含标题、一句话简介、封面、（可选）标签。
- **作品详情**：封面（可点跳转到对应仓库）、标题、标签、外链、正文（背景 / 我做了什么 / 结果）、上一篇 / 下一篇。
- **关于我**：头像、简介、（可选）技能与经历、社交链接。
- **联系入口**：邮箱、（可选）其他社交；**页头和页脚都能找到**。
- **加作品 = 加一个内容文件**，不动页面结构。

**B. 博客**（新增）
- **文章列表**：按发布时间倒序；每条显示标题、一句话摘要、发布日期、（可选）封面、标签。
- **文章详情**：标题、发布日期、正文、标签、上一篇 / 下一篇、返回列表。
- **写作方式**：一篇文章 = 一个内容文件，只写内容，不动页面。
- **空状态**：还没文章时给一句友好提示，不出现"空列表"的尴尬。
- **发布策略**：**自己站首发**；同步到外部平台时**标注原站出处**，让搜索认原创。
- 克制：博客不引入重动效，和作品集一样轻快。

**C. 多主题（明暗）**（新增）
- 三选一：**浅色 / 暗色 / 跟随系统**。
- 入口在页头，随手可切。
- **记住选择**：下次打开还是上次那套。
- 全站生效（含博客、404）。
- 切换**不闪烁**（不允许加载时先闪一下再变）。
- **明确不做**：明暗之外的"花哨主题"（海洋 / 森林等）。

**D. 多语言（中英 · 全站）**（新增）
- **每个页面都有中文和英文两版**：导航、首页、作品列表 / 详情、关于、博客、404。
- 页头有**语言切换**入口；切换后停留在**当前页的对应语言版本**（不是跳回首页）。
- **默认语言**跟随浏览器 / 地区推断；用户可手动覆盖并记住。
- 界面文案双语；内容（作品、文章）双语。
- **缺失回退**：某篇内容只写了一版时，另一种语言下**回退显示已有版本**并提示，而不是 404。

### 3.2 后续可以做

- **访问统计（轻量）**：看到**访问量**和**热门页面**；默认不采集个人身份信息，不需要 cookie 弹窗。
- 简历 PDF 下载。
- 项目按标签筛选 / 搜索。
- 联系表单。
- 页面过渡动画。
- 文章评论（谨慎：易招垃圾，放最后）。

## 4. 页面与信息架构

- **全局**：页头（名字 / 导航 / 语言切换 / 主题切换）；页脚（社交 + 版权）。
- **首页**：Hero → 精选作品 → 按分类浏览 → 关于摘要 → 联系。
- **作品**：列表页（含分类筛选）→ 分类页 → 详情页。
- **关于**：头像 + 简介 +（可选）技能 / 经历 + 社交。
- **博客**：文章列表 → 文章详情。
- **404**：友好文案 + 回首页。

---

## 5. 非功能性需求

- **性能**：Lighthouse 移动端各项 ≥ 90；首屏尽量轻（不加载不必要的脚本）；图片懒加载 + 显式尺寸。
- **可访问性**：语义化、对比度达标、键盘可导航、图片有替代文本；**明暗两套配色都要达标**。
- **兼容性**：主流现代浏览器最近两个大版本 + 移动端。
- **SEO**：每页有标题与描述、sitemap 可用；**中英两版各自可被索引**，并互相标注对应关系。
- **视觉稳定**：主题与语言切换**不得引起闪烁或布局跳动**。
- **可维护性**：加作品 / 加文章都只加一个内容文件。

---

## 6. 限制与边界（明确不做）

- ❌ 用户系统 / 登录
- ❌ 后台 CMS / 数据库
- ❌ 评论区（MVP 阶段）
- ❌ 中英之外的更多语言（MVP 只做中英）
- ❌ 明暗之外的花哨主题
- ❌ 花哨的预加载动画 / 全屏 3D（违背"快"的核心）
- ❌ 自建后端 / 服务端逻辑（访问统计用第三方服务）
- ⚠️ 博客**不要为了"显得有内容"而灌水**；宁可少写，也不写不真诚的东西。
